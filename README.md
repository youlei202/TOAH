# TOAH-ISAC (Code for the Task-Switch Stress Test)

This repository implements the core algorithmic code for **Task-Oriented Adaptive Hierarchy (TOAH)** in an online ISAC setting, plus a flagship experiment and visualization notebook.

## Repository layout

```text
toah_repo/
├─ toah/                       # core library (OOP, modular)
│  ├─ algorithms/              # TOAH + baselines
│  ├─ env/                     # mobility + channel + online environment
│  ├─ optim/                   # parameterizations and lightweight optimizers
│  ├─ utils/                   # seeding and complex helpers
│  ├─ config.py                # dataclass configs
│  └─ metrics.py               # comm/sensing metrics
├─ experiment/                 # runnable scripts (no CLI args needed)
│  └─ 00_task_switch_stress_test.py
├─ notebook/                   # visualization notebooks (save PDF vector figures)
│  └─ 00_task_switch_stress_test.ipynb
├─ data/                       # (optional) datasets
├─ result/
│  ├─ table/                   # per-run CSV outputs (for re-plotting without re-running)
│  ├─ artifact/                # saved artifacts (optional)
│  └─ figure/                  # PDF vector figures generated by notebooks
├─ .gitignore
└─ README.md
```

## Quick start

1) Install dependencies:
- Python 3.10+
- `torch`, `numpy`, `pandas`, `matplotlib`, `nbformat` (for notebooks)

2) Run the flagship experiment:

```bash
cd experiment
python 00_task_switch_stress_test.py
```

Outputs:
- `result/table/00_task_switch_timeseries.csv`
- `result/table/00_task_switch_summary.csv`

3) Visualize results:
- Open `notebook/00_task_switch_stress_test.ipynb`
- Run all cells
- Generated figures appear in `result/figure/` as **PDF vector** files.
