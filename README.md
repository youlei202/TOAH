# TOAH-ISAC (Code for Task-Oriented Adaptive Hierarchy in Online ISAC)

This repository implements the core algorithmic code for **Task-Oriented Adaptive Hierarchy (TOAH)** in an online integrated sensing and communication (ISAC) setting.

The repository also includes a set of experiments and visualization notebooks that match the evaluation plan in the paper draft.

## Quick start

### 1) Install dependencies

- Python 3.10+
- `torch`, `numpy`, `pandas`, `matplotlib`, `nbformat`

### 2) Run experiments

From the repository root:

```bash
python experiment/00_task_switch_stress_test.py
python experiment/01_switch_penalty_sweep.py
python experiment/02_truncation_depth_ablation.py
python experiment/03_scaling_runtime.py
python experiment/04_csi_clutter_robustness.py
python experiment/05_rsu_intersection_stress_test.py
python experiment/06_compute_budget_tradeoff.py
```

Each script writes per-run CSV files to `result/table/`.

### 3) Visualize and export PDF figures

Open the matching notebook under `notebook/` and run all cells.
All figures are saved as **PDF vector** files under `result/figure/`.
Aggregated tables (mean and standard deviation) are saved under `result/table/`.

## Notes on reproducibility

When `deterministic=True` and CUDA is available, PyTorch may require
`CUBLAS_WORKSPACE_CONFIG` for deterministic matrix multiplications.
The helper `toah.utils.seed.set_seed()` sets a safe default automatically.
